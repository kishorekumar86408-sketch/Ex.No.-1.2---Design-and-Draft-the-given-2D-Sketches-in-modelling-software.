# Ex.No.-1.2-Design and Draft the given 2D Sketches in modelling software.

## AIM
 To sketch the given drawing with dimensions using fusion 360 tool.
 
## REQUIREMENTS
 1. Autodesk fusion 360
 2. Windows 10
 3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
 4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
 
 ## PROCEDURE
 1.	Open new file and then select sketch icon.
 2.	Select the plane for sketching. 
 3.	Use sketching features (line, circle, arc, rectangle, polygon, etc.,) to draw the given sketch.
 <img width="263" height="527" alt="Screenshot 2026-11-01 204637" src="https://github.com/user-attachments/assets/5f591469-362e-4565-824d-c3fe31f3fa2d" />

 4.	Use sketch modifying features (cut, trim, mirror, move, etc.,) to edit the sketch.
    <img width="227" height="358" alt="Screenshot 2026-11-01 204722" src="https://github.com/user-attachments/assets/d8345348-97b8-4960-941a-0b53130cb178" />
 
 5.	Use inspect feature to measure the dimensions of sketch.
